# 스펙: 여행 경비 기록

작성일: 2026-11-17 · 상태: 초안

## 목표

여행 중 쓴 돈을 날짜별로 빠르게 적고, 날짜별·전체 합계를 본다. 환율·카드 내역 조회는 하지 않는다.

## 화면

- 탭에 **경비**를 추가한다(일정 편집 · 장소 찾기 · 시간표 · 당일 보기 · 경비).
- 위쪽 입력 줄: 날짜(기본값: 현지 오늘이 여행 기간이면 그날, 아니면 선택된 날) · 금액 · 통화 · 분류 · 메모(선택) · 추가.
- 아래 목록: 날짜별로 묶어 최신 순. 항목마다 수정·삭제. 날짜 묶음마다 소계.
- 맨 위 요약: 통화별 전체 합계, 분류별 합계. 환율을 입력했다면 원화 환산 합계(추정 표시).

## 데이터

```js
trip.expenses = [{ id, day: 0, amount: 1200, currency: 'JPY', category: 'food', note: '우동', createdAt }]
trip.exchangeRate = { JPY: 9.1 }   // 선택. 1 단위당 원화. 사용자가 입력
```

- 통화: JPY · KRW · USD · EUR · GBP. 새 항목의 기본 통화는 도시 나라 통화(일본 → JPY).
- 분류: 식비 · 교통 · 숙박 · 입장·체험 · 쇼핑 · 기타.
- 금액: 0보다 크고 1억 이하, 소수 둘째 자리까지(엔·원은 정수).
- 메모 100자. 여행당 항목 2,000개까지.
- 여행 기간을 줄여 없어진 날짜의 경비는 마지막 날로 옮긴다(삭제하지 않음).

## 저장·백업·내보내기

- 기존 저장 방식과 같다(실패 시 되돌리고 안내).
- 백업 v2에 `expenses`, `exchangeRate`를 포함한다. 없으면 빈 목록으로 읽는다. 복원 시 항목 id를 새로 발급한다.
- 텍스트 내보내기 끝에 "경비" 절(날짜별 항목, 통화별 합계)을 붙인다. 인쇄에는 넣지 않는다.

## 범위 밖

자동 환율, 카드·영수증 가져오기, 동행자 정산(누가 냈는지·나누기), 예산 목표.

## 검증

- 단위 테스트: 합계(통화별·분류별·날짜별), 환산, 입력 검증, 기간 단축 시 이동, 백업 왕복·검증 거부, 저장 실패 되돌리기, 텍스트 내보내기.
- 브라우저: 입력·수정·삭제 흐름, 320px 화면.
